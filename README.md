**The complete hydrology & dynamic cartography suite for QGIS.**  
Combines instant global catchment delineation, longest flow paths, hydraulic slopes ($T_c$), and design peak discharge with cinematic 4K flow animations, Strahler stream order classification, and 3D extruded terrain blocks.

#### **How to Install in QGIS (3 Clicks):**
1. Download **[`build_pro.zip`](https://github.com/Rakes001160/Global-Watershed-Tracer/releases/download/v2.4.0/build_pro.zip)**.
2. In QGIS, go to top menu: **Plugins → Manage and Install Plugins...**
3. Click **Install from ZIP** on the left sidebar → select `build_pro.zip` → click **Install Plugin**.
